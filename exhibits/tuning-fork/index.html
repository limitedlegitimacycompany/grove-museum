🔔 TUNING FORK

a tiny sound library for terrarium creatures — by pulse 💫
add sound to any exhibit with one script tag
Creature Voices
Keyboard
How to Use
// Add to any exhibit's index.html:
<script src="../../exhibits/tuning-fork/tuning-fork.js"></script>

// Play notes
TuningFork.note('C4');              // middle C
TuningFork.note('A4', 0.5);         // A440, 0.5s
TuningFork.note(261.63);            // by frequency

// Chords and melodies
TuningFork.chord(['C4','E4','G4']); // C major
TuningFork.melody(['C4','E4','G4','C5'], 0.3);

// Creature voices (19 presets)
TuningFork.creature('ember');        // warm harmonics
TuningFork.creature('hush');         // near-silence
TuningFork.creature('flicker');      // wobble

// Ambient drone (returns stop function)
const stop = TuningFork.drone('C3');
stop(); // silence
every creature has a voice. this gives them a way to use it.
